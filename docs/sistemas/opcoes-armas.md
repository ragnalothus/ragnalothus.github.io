# :crossed_swords: Opções das armas e Harword

## Toda arma que cai de monstro vem com bônus aleatórios

Toda arma que cai de um monstro (também de MVP) já nasce com **2 a 4 bônus aleatórios**:
2 garantidos e mais 2 com 40% de chance cada. Os bônus aparecem na descrição da arma.

Alguns exemplos do que pode sair:

| Tipo | Valores |
|---|---|
| FOR, AGI, VIT, INT, DES ou SOR | +1 a +3 |
| HP máximo / SP máximo | +100 a +500 / +20 a +80 |
| ATQ / ATQM | +5 a +15 |
| ATQ % / ATQM % | +1% a +3% |
| Precisão / Crítico | +3 a +10 / +2 a +5 |
| Velocidade de ataque | +1 ou +2% a +5% |
| Dano contra uma raça (físico ou mágico) | +2% a +6% |
| Dano contra um elemento | +2% a +6% |
| Dano contra um tamanho (físico ou mágico) | +2% a +6% |
| Dano em monstros normais ou em chefes (físico ou mágico) | +2% a +5% |
| Dano crítico | +3% a +10% |
| Dano à distância / corpo a corpo | +2% a +5% |
| Conjuração / pós-conjuração | -2% a -5% |
| Arma indestrutível | (raro) |

A mesma arma nunca tem o mesmo bônus duas vezes. O 5º espaço de bônus fica livre para o
[Refino das cartas](ferreiro-e-refino.md#refino-das-cartas-1-a-10).

## Harword: sortear de novo

O **Harword** fica na [Central do Aventureiro](../npcs/central-aventureiro.md) (46,59). Ele sorteia de novo
os bônus de **qualquer arma** do seu inventário, inclusive das que não têm nenhum (compradas, forjadas...).

- Preço do sorteio: **1.000.000z + 20 Moedas de Loki**.
- Você pode **travar até 2 bônus** para não perdê-los: cada bônus travado custa **+50 Moedas de Loki**.
- O sorteio novo pode dar menos bônus do que a arma tinha (nunca menos que os travados).
- O Refino das cartas da arma nunca muda.
