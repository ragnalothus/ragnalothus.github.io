# :crown: Legado da conta

Cada personagem da sua conta que chega ao **nível de base 99** deixa um **bônus pequeno** para **todos os personagens da conta, inclusive ele mesmo**. O bônus depende da classe dele.

- O próprio personagem 99 também recebe o bônus da classe dele.
- Transcendental e bebê contam como a classe normal (Lorde = Cavaleiro, Bebê Bruxo = Bruxo).
- Cada classe conta **uma vez**: dois Cavaleiros 99 dão um bônus de Cavaleiro.
- Os bônus são somados ao **entrar no jogo**. Se um personagem chegou ao 99 agora, saia e entre de novo para ganhar o bônus dele (nele e nos outros).
- Use **`@legado`** para ver os bônus do personagem e a lista completa.

| Classe 99 na conta | Bônus para todos os personagens da conta |
|---|---|
| Cavaleiro | +5% de HP máximo |
| Templário | +5 de DEF |
| Monge | +5 de FOR |
| Sacerdote | +10% de cura das habilidades e +10% de HP recuperado com itens de cura |
| Bruxo | +2% de ATQM |
| Sábio | +5 de INT |
| Caçador | +5 de DES |
| Bardo | +5% de dano à distância |
| Odalisca | +4% de SP máximo |
| Mercenário | +5 de AGI |
| Arruaceiro | +5 de SOR |
| Ferreiro | +2% de ATQ |
| Alquimista | +5% de cura das poções |
| Super Aprendiz | +2 em todos os atributos |
| Taekwon | +5 de Esquiva |
| Mestre Taekwon | +5 de DEFM |
| Espiritualista | +5 de VIT |
| Justiceiro | +5 de Precisão |
| Ninja | +4 de Esquiva Perfeita |

Com todas as 19 classes no 99, um personagem novo da conta já começa com todos esses bônus.
