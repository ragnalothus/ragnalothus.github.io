# :crown: Legado da conta

Cada personagem da sua conta que chega ao **nível de base 99** deixa um **bônus pequeno** para **todos os outros personagens da conta**. O bônus depende da classe dele.

- O personagem 99 **não recebe o próprio bônus**: ele vale para os outros.
- Transcendental e bebê contam como a classe normal (Lorde = Cavaleiro, Bebê Bruxo = Bruxo).
- Cada classe conta **uma vez**: dois Cavaleiros 99 dão um bônus de Cavaleiro.
- Os bônus são somados ao **entrar no jogo**. Se um personagem chegou ao 99 agora, entre de novo com os outros para ganhar o bônus dele.
- Use **`@legado`** para ver os bônus do personagem e a lista completa.

| Classe 99 na conta | Bônus para os outros personagens |
|---|---|
| Cavaleiro | +2% de HP máximo |
| Templário | +3 de DEF |
| Monge | +2 de FOR |
| Sacerdote | +3% de poder de cura |
| Bruxo | +2% de ATQM |
| Sábio | +2 de INT |
| Caçador | +2 de DES |
| Bardo | +2% de dano à distância |
| Odalisca | +2% de SP máximo |
| Mercenário | +2 de AGI |
| Arruaceiro | +2 de SOR |
| Ferreiro | +2% de ATQ |
| Alquimista | +5% de cura das poções |
| Super Aprendiz | +1 em todos os atributos |
| Taekwon | +3 de Esquiva |
| Mestre Taekwon | +3 de DEFM |
| Espiritualista | +2 de VIT |
| Justiceiro | +3 de Precisão |
| Ninja | +1 de Esquiva Perfeita |

Com todas as 19 classes no 99, um personagem novo da conta já começa com todos esses bônus.
