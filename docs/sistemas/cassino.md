# :slot_machine: Cassino de Comodo

Apostas em **zeny** no salão do cassino de Comodo. A **Guia do Cassino** na [Central do Aventureiro](../npcs/central-aventureiro.md) (36,58) leva até lá.
Aposta de **1.000z a 1.000.000z**. Jogue com moderação: a casa sempre fica com um pouco.

## Crupiê

| Jogo | Aposta | Paga |
|---|---|---|
| Dados (2 dados) | Baixo (2 a 6) ou Alto (8 a 12) | 2,2x |
| | Sete | 5x |
| Roleta (0 a 36) | Vermelho/Preto ou Par/Ímpar | 2x (o 0 perde) |
| | Um número | 36x |
| Caça-níquel | 3 Jellopy / 3 Maçãs / 3 Porings / 3 Moedas / 3 Setes | 4x / 8x / 25x / 150x / 2.000x |
| | Um 7 sem trinca | 2x |
| | 2 iguais | devolve a aposta |

## Corrida de Monstros

A cada **3 minutos**, 6 monstros sorteados correm na pista do cassino. As apostas ficam abertas por 2 minutos com o **Agenciador da Corrida**: cada monstro tem uma **cotação** (quanto paga). Ganhou, recebe na hora (ou pelo correio, se tiver saído do jogo).

Ganhos de 5.000.000z ou mais são anunciados no servidor.

A corrida de monstros oficial de Hugel (com medalhas) continua lá, como sempre.
