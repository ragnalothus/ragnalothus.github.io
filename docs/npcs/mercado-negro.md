# Mercado Negro

Fale com o **Mercado Negro** em Prontera (162,187) para entrar. Para voltar, fale com o NPC **Retornar** lá dentro.

São mais de 40 lojas. Os preços aparecem na janela de cada loja.

| Tipo | Lojas |
|---|---|
| **Chapéus** | Vendedor de Hats 1 a 4, Hats, Hats bRO 1 a 3 |
| **Cartas** | Cabeça, Armadura, Escudo, Capa, Sapato, Acessório, Arma, MVP e Miniboss |
| **Armas** | Adagas, Espadas, Espadas de Duas Mãos, Lanças, Machados, Maças, Cajados, Livros, Katares, Punhos, Arcos, Instrumentos, Chicotes, Armas (outras) |
| **Equipamentos** | Armaduras, Escudos, Capas, Calçados, Acessórios |
| **Munição e consumíveis** | Flechas, Projéteis, Shurikens 1 e 2, Pedras, Gemas, Pergaminhos (Scroll) |
| **Classes** | Alquimista, Forjador, Itens de Aprendiz |
| **Outros** | Bonecas |
