# :keyboard: Comandos

Comandos que qualquer jogador pode usar.

| Comando | O que faz |
|---|---|
| `@go 0` ou `@go prontera` | Leva para Prontera (o `@go` só funciona para Prontera) |
| `@vip` | Leva para a Sala VIP e mostra até quando vai o seu VIP |
| `@pontos` | Mostra quantas Moedas Douradas você tem e como ganhar mais |
| `@rankmvp` | Ranking de MVPs da semana e do mês |
| `@rankpvp` | Sua divisão no [Ranking PvP](../eventos/arena-pvp.md#ranking-pvp) e a fila das lutas ranqueadas (entrar e sair) |
| `@copa` | Menu da [Copa Lothus](../eventos/arena-pvp.md#copa-lothus): inscrição, fila, classificação e prêmios |
| `@passe` | Abre o [Passe de Batalha](../sistemas/passe-batalha.md): nível, pontos de hoje e prêmios |
| `@faccao` | Abre as [Facções](../sistemas/faccoes.md): escolher a facção, placar da semana por categoria, seus pontos, ranking, Guerra de Facção e loja das Fichas de Facção |
| `@colecao` | Abre a [Coleção de Monstros](../sistemas/colecao-monstros.md) da conta |
| `@padrinho <nome>` | Pede um veterano como [padrinho](../sistemas/padrinho.md); `@padrinho` sozinho aceita pedidos e mostra seus afilhados |
| `@mergulho` | Abre ou entra no [Mergulho no Abismo](../sistemas/mergulho.md) do grupo; lá dentro mostra a profundidade e `@mergulho sair` sai com os prêmios |
| `@duelo` | Abre o [Duelo de Cartas](../sistemas/duelo-cartas.md) (se você estiver num duelo, volta para ele) |
| `@duelo desafiar <nome>` | Desafia outro jogador para um [Duelo de Cartas](../sistemas/duelo-cartas.md#contra-outro-jogador), com aposta opcional de Moedas de Loki |
| `@duelo aceitar` / `@duelo recusar` | Responde ao desafio recebido (vale por 60 segundos) |
| `@duelo torneio` | Menu do [Torneio semanal](../sistemas/duelo-cartas.md#torneio-semanal) de Duelo de Cartas (inscrição, prêmios, campeões) |
| `@acoes` | Abre a [Bolsa de Ações](../sistemas/bolsa-acoes.md) |
| `@guildas` ou `@bancoguilda` | [Banco da guilda, ajuda para guilda nova e recrutamento](../sistemas/guildas.md) |
| `@protecao` | Liga ou desliga a [Proteção de itens](../sistemas/servicos.md#protecao-de-itens) da conta |
| `@galeria` | Abre a [Galeria de Cartas](../sistemas/galeria.md): o álbum de cartas da sua conta |
| `@r <resposta>` ou `@resposta <resposta>` | Responde a pergunta do [Quiz](../eventos/quiz.md) |
| `@arena` | Entra na fila da [Arena Lothus](../eventos/arena-lothus.md) |
| `@arena sair` | Sai da fila da Arena Lothus |
| `@torres` | Dentro da Arena: vida das torres e cristais de pé |
| `@die` | Mata o seu personagem |
| `@autoloot`, `@alootid`, `@autoloottype` | Pega os itens que caem dos monstros automaticamente |
| `@feelreset` | Só Mestre Taekwon: apaga os mapas do Sol, da Lua e das Estrelas |
| `@config` (ou `@configuracoes`) | Janela para deixar ligados o autoloot, `@noask`, `@showexp`, `@showzeny`, `@noks` e a Proteção de itens: fica salvo e volta sozinho ao entrar. [Serviços](../sistemas/servicos.md#configuracoes-que-ficam-salvas-config) |
| `@whosell` ou `@ws` (sozinhos) | Abrem a janela de Busca de Lojas do jogo (vender ou comprar, em todos os mapas). [Serviços](../sistemas/servicos.md#procurar-lojas-ws-e-wb) |
| `@whosell <item>` ou `@ws <item>` | Abre a janela de Busca de Lojas já com quem vende o item; aceita o número do item ou o nome. [Serviços](../sistemas/servicos.md#procurar-lojas-ws-e-wb) |
| `@ws2 <item>` | Quem está vendendo o item, do mais barato para o mais caro. Filtros: `+refino` e `mín-máx`. [Serviços](../sistemas/servicos.md#procurar-lojas-ws-e-wb) |
| `@wb <item>` (ou `@wb2`, `@whobuy`) | Quem está comprando o item, do que paga mais para o que paga menos |
| `@at` | Deixa a sua loja (de venda ou de compra) aberta enquanto você está fora |
| `@evento` | Entra no evento automático com inscrição aberta (todos os eventos da noite com inscrição; no Seja o MVP, também entra como caçador nos 5 primeiros minutos). [Eventos automáticos](../eventos/automaticos.md) |
| `@joinbg` | [Battleground](../eventos/battleground.md): inscrição nos 5 minutos antes ou, com a batalha rodando, entra no time com menos gente |
| `@leavebg` | Sai do Battleground e volta para onde estava |
| `@bginfo` | Mostra a batalha que está rodando (jogadores, placar e tempo) |
| `@bgranking` | Ranking das batalhas do Battleground |
| `@listenbg` | Liga ou desliga os avisos de Battleground no chat |
| `@order`, `@leader`, `@reportafk`, `@bgskill` | Comandos do líder do time no Battleground. [Líder do time](../eventos/battleground.md#lider-do-time) |
| `#forca <letra ou palavra>` | Chute na [Forca](../eventos/automaticos.md#forca) (também `@forca`) |
| `@bolsa` | Na [Extração](../eventos/automaticos.md#extracao): mostra a bolsa do evento e as saídas abertas |
| `@detetive` | No Detetive: suas cartas, anotações automáticas (o que já te mostraram) e a sua jogada. [Detetive](../eventos/detetive.md) |
| `@logindiario` | Abre a janela do [login diário](../sistemas/login-diario.md) para ver os prêmios do mês |
| `@sorteio` | Inscrição no [Sorteio Diário](../sistemas/rankings-e-loteria.md#sorteio-diario) e o prêmio de hoje |
| `@mapexp` | Mostra os [Mapas de EXP e a Masmorra do Dia](../sistemas/mapas-exp.md) |
| `@espelho` | Espelho Convexo: lista os MVPs vivos nos mapas (salas privadas e instâncias não aparecem) |
| `@dance <1-9>` | Faz o seu personagem dançar (9 danças) |
| `@autobuff` | Só VIP: os buffs de 1 hora da Curandeira VIP sempre renovados (fora de PvP, GdE e campos de batalha). [VIP](../servidor/vip.md) |
| `@boneco` | Dentro da Sala de Treino: cria e troca os bonecos de treino. [Serviços](../sistemas/servicos.md#sala-de-treino) |

## Oração do Super Aprendiz

No nível 99, o Super Aprendiz que fizer a oração do anjo ganha a **Fúria de Crítico** a cada 20 minutos.
Veja [Classes](../mudancas/classes.md#super-aprendiz).
