## Visuais Limitados (aba Limited)

- **Toda segunda-feira às 20h** a aba Limited recebe **9 visuais novos**.
- Cada visual custa **10.000** de cash.
- Um visual que saiu da aba só volta depois de **2 meses**.
- Se você já estava online na troca, entre de novo no jogo para ver a lista nova.

Os visuais são os mesmos da [Chapeleira](../sistemas/chapeleira.md): só aparência, sem atributos.

## Como conseguir cash (ROPs)

- Gerente de Moedas Douradas: 1.000 ROPs por 500 Moedas Douradas. [Moedas](moedas.md)
- Trocador de Bandeiras, pelo menu do NPC.
