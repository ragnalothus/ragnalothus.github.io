# Rates

## Semana (segunda a sexta)

| | |
|---|---|
| EXP de base | 10x |
| EXP de classe | 10x |
| Drop de itens | 9x |
| Cartas (normais, miniboss e MVP) | 1% fixo |
| Drop de MVP | 5x |

## Fim de semana

| | Quando | |
|---|---|---|
| EXP de base | Sábado 00h até domingo 23h59 | 13x |
| EXP de classe | Sábado 00h até domingo 23h59 | 13x |
| Drop de itens | Sábado 00h até domingo 23h59 | 12x |
| Drop de MVP | Sábado 00h até domingo 23h59 | 9x |

A troca é automática. As **cartas ficam sempre em 1%**, também no fim de semana.

## ASPD máxima

A velocidade de ataque (ASPD) máxima do servidor é **193**.

## Outros bônus

- **[Dia das Raças](../sistemas/dia-das-racas.md):** +10% de EXP contra a raça de monstro do dia.
- **Moeda de Loki:** 5% de chance em quase todo monstro, direto no inventário. Não muda com as rates. [Moedas](moedas.md)
- O VIP **não** dá bônus de EXP nem de drop.

## Outras configurações

- **Conjuração instantânea com 100 de DES.**
- **Intimidade de pet e de homúnculo x3.**
- **Penalidade de morte:** Aprendiz e Super Aprendiz não perdem EXP.
